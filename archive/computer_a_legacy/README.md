# Computer A Legacy Archive

Exact-byte recovery performed on 2026-09-24. Source files were copied from `D:\` without modifying, moving, or deleting the originals. Every imported original or ZIP entry is recorded in `SOURCE_PROVENANCE.csv` with size and SHA-256.

This archive contains historical and potentially state-changing experiments. Nothing here is approved for automatic execution. In particular, files under `historical_restart_scripts/`, `x55_wfc_oneclick/`, and `zip_unique/` are historical evidence and must be reviewed independently before any use.

Current practical tools live under `tools/`; this archive is for provenance and reproducibility. Large raw logcat, system/vendor binaries, ZIP containers, and unknown kernel modules remain on Computer A and are indexed in `docs/COMPUTER_A_RAW_EVIDENCE_MANIFEST.csv`.
