# VOXI WFC Recovery v1.1 Release

Install `VOXI-WFC-Recovery-v1.1.zip` through Magisk. The module is fixed to the validated Xiaomi 14 Pro dual-SIM identity documented in `module/README.md`.

Safe Recover was validated in 3/3 identical recovery cycles. The manual F1 Deep Recover sequence was validated once on a preserved real F1 scene and remained directly healthy for 301 seconds across 31/31 samples.

The release does not include a WebUI and has not been installed as part of this build. Engineering tests are limited to static checks, shell syntax, ZIP structure, current healthy status, and healthy Action zero-write behavior.
